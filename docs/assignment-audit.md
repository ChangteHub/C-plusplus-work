# 学校人员管理系统要求完成清单

依据用户提供的《2026-C++程序设计-大作业习题及报告模板.docx》第 2 题及详细评分表，更新日期 2026 年 10 月 11 日。本清单对应实际实现与测试，不预测教师评分。

## 题目六项要求

| 要求 | 实现与验证 | 状态 |
| --- | --- | --- |
| 基本人员及开户、销户、登录、本人资料 | Person 公共字段；个人开户/管理员开户、Cookie 登录/退出、改密码、本人确认销户，个人资料页 | 已完成，账号与权限测试通过 |
| 教师、学生，本科生与研究生 | Teacher、Student、Undergraduate、GraduateStudent；界面区分类别，兼容旧学生记录 | 已完成 |
| 教师职称、部门、输入保存及本人查看 | 教师录入、数据库保存、个人页，另有授课课程和成绩维护 | 已完成，浏览器验收通过 |
| 学生各门课程、成绩与已录入学生排名 | 课程/成绩表、本人课程页；整数成绩排序，同分 1、1、3，未录入不排名 | 已完成，边界、权限及排名测试通过 |
| 研究生由教师与学生派生，研究方向、导师及本人查看 | GraduateStudent 同时继承 Teacher、Student，两父类虚继承 Person；方向导师贯穿录入、存储、编辑和个人页 | 已完成，C++ 测试验证唯一 Person 子对象 |
| 所有用户信息保存在文件 | SQLite 保存人员、账号、会话、课程和成绩；完整 JSON 文件流写出/回读；控制台文本保存人员 | 已完成，导出与重启测试通过 |

完整题目业务在 Web 版实现。控制台保留人员管理和文本文件功能，与 Web 数据独立；没有把控制台描述成具备完整账号、课程和成绩功能。

## 报告和验证

报告材料 docs/report.md 包含封面/任务书、五个正文部分、关键代码、UML、算法图、运行结果与分析，以及六项 2023–2026 年参考文献。个人信息按用户要求留空，签名和教师评分亦留空。

Word 排版验收尚未完成：文档技能要求渲染 DOCX 并逐页检查，而当前 Windows 捆绑运行时没有 LibreOffice，模板渲染返回 soffice.exe was not found on PATH。没有交付未验收的 DOCX；格式要求与后续流程见 docs/report-format.md。

最终 Windows 编译启用 -Wall -Wextra -Wpedantic，无警告。16 组接口回归、7 组作业验收、控制台测试和 C++ 模型测试通过。浏览器确认了管理员管理、研究生方向导师、教师个人页/授课课程、学生成绩排名，错误日志为空。

服务器新版本已发布到 https://swustmarket.xyz，Ubuntu 模型、16 组接口、7 组新增验收及控制台测试通过，公网账号、权限、排名、导出和重启保存验收通过。原有 1 条人员记录逐字段保留，临时验证资料已清理，发布前后完整备份已保存，详见 deploy/README.md。
