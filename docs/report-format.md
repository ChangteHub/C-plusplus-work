# 报告排版说明

原模板为用户提供的 2026-C++程序设计-大作业习题及报告模板.docx，保持原文件不变。report.md 是已填写的正文和任务书材料，report-assets/ 保存真实运行截图、UML 和算法图。

封面沿用模板校名、学院、课程名称，题目填“学校人员信息管理系统”。专业班级、姓名、学号、指导教师、邮箱留空；师生签名和教师评分由本人及教师实际填写。日期使用实际提交日期，本轮整理日期 2026 年 10 月 11 日。

| 内容 | 模板格式 |
| --- | --- |
| 设计题目 | 小二号黑体居中，段前 0 行，段后 0.5 行 |
| 五个正文部分标题 | 四号黑体顶格，段前 5 磅，段后 2.5 磅 |
| 正文 | 小四号宋体，22 磅行距 |
| 关键代码 | 五号 Times New Roman，单倍行距，中文注释用可显示中文的字体 |
| 图题 | 五号宋体居中，按示例加粗，连续编号 |
| 参考文献 | 五号宋体，悬挂缩进，22 磅行距；六条为 2023–2026 年资料 |

图与题不拆页，代码选自关键自编业务，不粘贴第三方库全文。打印不包含“课程设计注意事项”、本文件或排版状态说明。电子稿和打印稿的截止时间依教师通知。

当前 Word 排版验收受阻：Windows 捆绑运行时没有 LibreOffice。2026 年 10 月 11 日运行文档技能 render_docx.py 检查原模板，得到 FileNotFoundError: LibreOffice soffice.exe was not found on PATH。技能要求交付前渲染并逐页检查，且不得改用用户桌面安装的 LibreOffice，因此暂不交付未经验收的 DOCX。

后续在具有捆绑渲染器的环境中以原模板为依据，将报告内容填入封面、任务书和五个正文位置，保留评分表，按规定排版，再渲染并逐页检查。没有伪造个人经历、签名、学号或教师评分。
